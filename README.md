# DietDiary 🥗 다이어트 루틴 다이어리

식단 관리, 운동 스케줄, 다이어트 습관을 **하나의 루틴**으로 관리하는 자기관리 웹앱입니다.
루틴 앱처럼 시간대별 습관을 체크하고 타이머로 실행하면서, 식단 칼로리와 요일별 운동 계획까지 함께 기록할 수 있어요.

휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 일반 앱처럼 전체 화면으로 실행되고, 인터넷이 없어도 동작합니다 (PWA).

## 주요 기능

| 탭 | 기능 |
|---|---|
| **오늘** | 주간 날짜 스트립, 하루 달성률 링, 아침·오후·저녁·자기 전·언제든 **시간대별 루틴 체크**, ▶ **루틴 시작**(타이머로 하나씩 진행·초과 시간 표시), 오늘은 쉬기, 체중·물·식단·운동 요약, 기분 + 한 줄 일기 |
| **식단** | 하루 목표 칼로리 링(목표 − 음식 + 운동), 탄·단·지 목표, 물 마시기, 아침/점심/저녁/간식 기록, **음식 180여 개 검색(초성 검색 지원: ㄷㄱㅅㅅ → 닭가슴살)**, 직접 입력·내 음식 저장, 이전 식단 불러오기, 식단 사진 |
| **운동** | **요일별 주간 운동 계획 직접 작성**(샘플 계획 제공, 다른 요일로 복사), 날짜별 세트 체크(무게×횟수/횟수/시간), 세트 사이 **휴식 타이머**, 운동 전체를 순서대로 실행하는 플레이어, 소모 칼로리 추정(MET) |
| **리포트** | 주간/월간 루틴 달성률, **신호등 달력**(80%↑ 초록 · 50%↑ 노랑 · 미만 빨강) + 기분 이모지, 루틴별 실천율, 연속 실천일, 일별 섭취 칼로리·탄단지 비율, 운동 시간·소모 칼로리, 체중 변화 그래프 |
| **나** | 프로필·목표 체중, BMI(대한비만학회 기준)·기초대사량·활동대사량(Mifflin-St Jeor)·권장 칼로리 자동 계산, 체중 기록, 다크 모드, 루틴 알림, 백업 내보내기/복원, 설치 안내 |

- 서버 없이 동작하는 순수 HTML/CSS/JavaScript (빌드 과정, 외부 라이브러리 없음)
- 모든 기록은 **이 기기의 브라우저(localStorage / IndexedDB)** 에만 저장됩니다. 휴대폰을 바꾸기 전에 `나 → 백업 파일 내보내기`로 백업하세요.

## GitHub Pages로 배포하기

1. GitHub 저장소 → **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: 앱 파일이 있는 브랜치(예: `main`) / 폴더 `/ (root)` 선택 → **Save**
4. 1~2분 뒤 `https://<아이디>.github.io/DietDiary/` 주소로 접속할 수 있어요.

> 모든 경로가 상대 경로라서 `아이디.github.io/저장소이름/` 하위 경로에서도 그대로 동작합니다.
> `https://<아이디>.github.io/` 처럼 저장소 이름 없는 주소를 원하면, 저장소 이름을 `<아이디>.github.io` 로 만들어 같은 파일을 올리면 됩니다.

## 휴대폰에 앱처럼 설치하기

- **아이폰 (Safari)**: 사이트 열기 → 하단 **공유 버튼** → **홈 화면에 추가**
- **안드로이드 (Chrome / 삼성 인터넷)**: 사이트 열기 → 메뉴 **⋮** → **앱 설치** 또는 **홈 화면에 추가**
  (앱 안의 `나 → 앱으로 설치` 버튼으로도 설치할 수 있어요)

## 업데이트 배포 시

파일을 수정해 배포할 때는 `sw.js` 의 `VERSION` 값을 올려주세요. 그래야 이미 설치한 사용자에게 **"새 버전이 준비됐어요 → 업데이트"** 알림이 뜨고 새 파일이 적용됩니다.

## 로컬에서 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 폴더 구조

```
index.html              앱 셸
manifest.webmanifest    PWA 설정 (이름, 아이콘, 바로가기)
sw.js                   서비스워커 (오프라인 캐시, 업데이트)
css/app.css             스타일 (라이트/다크 모드)
icons/                  앱 아이콘
js/app.js               라우팅·렌더링·공통 동작
js/store.js             데이터 저장 + 칼로리/달성률 계산
js/views/               오늘·식단·운동·리포트·나·온보딩 화면
js/data/                음식 DB, 운동 라이브러리, 추천 루틴
js/player.js            루틴/운동 타이머 플레이어
js/resttimer.js         세트 휴식 타이머
js/photos.js            식단 사진 저장 (IndexedDB)
js/reminders.js         루틴 알림
```

## 참고

- 칼로리·영양 정보는 일반적인 1회 제공량 기준 **추정치**이며 의학적 조언을 대신하지 않습니다.
- 루틴 알림은 정적 사이트 특성상 **앱이 열려 있을 때**만 울립니다 (서버 푸시 없음).
